## Gossip implementation check

Targeted inspection of `app/peer.py` established the frozen path:

```text
strategy=gossip -> PeerState.target_peers(sender_id)
candidates = unique physical neighbours excluding sender, self, and unavailable neighbours
default_fanout=None -> return all candidates in stable topology order
integer fanout -> self.rng.sample(candidates, min(default_fanout, len(candidates)))
gRPC receive path = PeerService.Forward -> PeerState.process_envelope
first reception logs received_new, selects targets, and starts forward_to_peer threads
duplicate reception logs received_duplicate and returns before target_peers
successful sends log forward; GetStatus exposes seen_count
```

Isolation by construction and branch inspection:

```text
strategy=gossip => ahbn_controller=None, ahbn_state=None, StandaloneObservationSink
adaptive_update returns immediately unless strategy==ahbn
cluster_targets is only called by strategy==cluster or the AHBN branch
dcsoc_maintenance is only constructed for strategy==dcsoc
Gossip target selection reads only physical neighbors/default_fanout/RNG/unavailable set
```
