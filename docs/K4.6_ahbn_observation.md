## Kubernetes observation mapping

| Input | Runtime source | Normalization | Controller field | Range |
|---|---|---|---|---|
| `d_t` | interval receives and duplicate classifications | duplicates / receives; empty window 0 | `snapshot.d` → `duplicate_obs` → `raw_d` | [0,1] |
| `l_t` | mean one-hop time since `sent_at`, after controlled local delay | `min(1, mean_seconds / 1.0 second)` | `snapshot.l` → `latency_obs` → `raw_l` | [0,1] |
| `u_t` | authoritative `InjectOverload`/`ClearOverload` processing-pressure state | `1.0 if overload_ms > 0 else 0.0` | `snapshot.u` → `utilization_obs` → `raw_u` | {0,1} |
| `c_t` | interval join/leave records from neighbor availability changes | `min(1, (joins+leaves)/max(neighbor_count,1))` | `snapshot.c` → `churn_obs` → `raw_c` | [0,1] |
