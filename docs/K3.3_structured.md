## F. Frozen ControlSim Structured semantics

Inspected `ahbn/strategies/cluster.py`, `ahbn/cluster.py`, `ahbn/node.py`,
`ahbn/simulator.py`, `ahbn/topology.py`, `run_one.py`, and `run_batch.py`.

- Static clusters record member lists and one head per cluster; consecutive
  cluster heads are deterministic gateway neighbors.
- A member selects only its active head, unless that head is self or the
  immediate sender. There is no fallback.
- A head selects active members followed by active gateway heads, excluding
  self and immediate sender and deduplicating in first-occurrence order.
- Standalone construction is `ClusterStrategy()` (`fanout=None`), returning
  every eligible structural obligation.
- A numeric budget exists only when ClusterStrategy is invoked by canonical
  AHBN. It preserves a gateway where possible and truncates to AHBN's budget.
- Standalone Structured uses no sampling, shuffle, RNG, AHBN controller, or
  AHBN observation/control state.
- Failed/inactive structural targets are omitted; there is no head election,
  Gossip fallback, reclustering, or reconstruction for this comparator.
- The simulator returns on duplicates before strategy selection. Initial
  source delivery enters the same receive/strategy path and follows its role.

## G. Existing Kubernetes Structured behavior

Call path: experiment YAML → `app/gen_topology.py` → topology JSON/ConfigMap →
`PeerState.__init__` → `process_envelope` duplicate gate →
`target_peers(sender_id)` → `cluster_targets` → `forward_to_peer`.

Before repair, the standalone `strategy == "cluster"` branch correctly called
`cluster_targets` without a fanout, never sampled, and never invoked
`adaptive_update`. Members selected only their head; heads selected all
members plus gateways with deterministic deduplication and sender/self
exclusion. Gaps: known-unavailable structural targets were not filtered; the
generator/config misleadingly carried fanout 3; and every standalone peer
still instantiated/fed the AHBN observation adapter even though it had no
controller or AHBN state.
